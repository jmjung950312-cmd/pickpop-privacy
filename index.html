정정 안내 (2026-11-15)

이전 판은 "광고를 게재하지 않으며 광고 식별자(IDFA)를 사용하지 않는다"고 적었지만, 앱스토어에 공개된 iOS 버전에는 이미 Google AdMob 광고가 들어 있었습니다. 실제 동작에 맞게 바로잡습니다.

1. 저희가 수집하는 개인정보 — 없음

회원가입·로그인이 없고, 저희(루프랩스) 서버로 보내는 정보가 없습니다. 앱에 적은 이름·선택지·금액과 광고 간격용 판 수(1.0.4부터)는 기기 안에만 저장되고, 앱을 지우면 함께 지워집니다.

2. 광고 (Google AdMob)

판 사이에 전면 광고가 나옵니다. Google이 앱 안의 광고 도구로 아래 정보를 직접 처리하며, 해외(미국 등) 서버로 전송됩니다. 이 정보는 저희에게 오지 않습니다.

  • 광고 식별자(iOS IDFA — 추적 허용 시에만 / Android 광고 ID)
  • IP로 추정한 대략적 위치
  • 광고 상호작용, 앱 사용·성능·진단 기록

3. 추적 거부 방법

iPhone: 광고 전에 묻는 "앱이 추적하도록 허용"에서 거부하거나, 설정 → 개인정보 보호 및 보안 → 추적에서 끕니다. 거부해도 모든 기능을 쓸 수 있고 일반 광고만 나옵니다.

Android: 설정 → Google → 광고에서 광고 ID를 삭제하거나 재설정합니다.
